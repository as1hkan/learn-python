# Day 1

## Getting Started
Today I started my Python learning journey, building on my previous experience with C# and Unity.

## What I Learned
- How to take input from the user using `input()`
- How to convert input to numbers using `int()`
- How to use `if`, `elif`, and `else` for decision making

## What I Built
I created a simple program that:
- asks for the user's name
- asks for the user's age
- tells how many years are left until 50 (or how many years have passed)

## Challenges
- Adjusting to Python’s syntax compared to C#
- Remembering that `input()` always returns a string
- Structuring conditions correctly

## Notes
- Python is more concise than C#, especially for simple scripts
- Condition order is important
- Handling edge cases improves code quality

## Reflection
A quick but useful refresher on basic concepts in Python, with focus on syntax differences and writing clean conditional logic.

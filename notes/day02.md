# Day 2

## Topics Covered
- `while` and `for` loops
- `break` statement
- `random` module (`randint`)
- user input inside loops

## What I Learned
- Loops allow repeating actions until a condition is met
- `for` loops can control the number of attempts
- `while` loops can run indefinitely until stopped
- `break` is used to exit a loop when a condition is satisfied
- The `random` module helps create dynamic behavior in programs

## What I Built
Today I built a simple number guessing game:
- The program generates a random number
- The user has limited attempts to guess it
- The program gives feedback (too high / too low)
- The game ends when the number is guessed or attempts run out

## Challenges
- Understanding how loops work in practice
- Controlling the number of attempts
- Structuring conditions correctly inside the loop

## Notes
- Loops are essential for interactive programs
- Combining loops with conditions creates powerful logic
- Small projects help reinforce concepts much better than theory

Today was a big step forward. I moved from simple scripts to building an interactive program using loops and logic.
